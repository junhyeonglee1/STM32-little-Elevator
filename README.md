DC모터를 활용한 소형 엘리베이터 구현

1. DC모터를 활용하여 엘리베이터 모터 활용
2. 포토커플러 외부 인터럽트를 활용하여 층 구별
3. 버튼을 통해서 층 및 엘리베이터 제어
4. 도트매트릭스와 I2C LCD를 활용하여 현재상태 Display
5. 층 입력 및 취소기능
